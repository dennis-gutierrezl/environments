# Node.js 26 Backend Environment (DevContainer + Docker Compose)

Reproducible development and production-ready container environment for **Node.js 26 (LTS)** backend applications (NestJS, Express, Fastify, Hono, workers) using **pnpm**, **VS Code DevContainers**, **Docker Compose**, and a multi-stage `node:26-slim` production `Dockerfile`.

---

## Prerequisites

* [Docker Engine](https://docs.docker.com/engine/install/) / Docker Desktop with Docker Compose v2
* [Visual Studio Code](https://code.visualstudio.com/)
* [Dev Containers](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers) extension

---

## Project Convention

The `Dockerfile` expects a standard TypeScript/Node.js build pipeline so it works without modifications:

```text
.
├── .devcontainer/
│   └── devcontainer.json
├── src/                      # Application source code
├── dist/
│   └── main.js               # Compiled entry point (generated by `pnpm run build`)
├── package.json
├── pnpm-lock.yaml
├── .dockerignore
├── .env                      # Local variables (do not commit)
├── .env.example              # Environment template
├── compose.yaml              # Development app service
├── infrastructure.yaml       # Local infrastructure services
└── Dockerfile                # Multi-stage (development, build, final)
```

> **Important:** The production stage runs `node dist/main.js`. Ensure your `package.json` defines a `build` script that outputs the entry point to `dist/main.js` (default in NestJS).

## Quick Start

1. **Configure environment variables:**
   ```bash
   cp .env.example .env
   ```

2. **Open in DevContainer:**
   * Open the folder in VS Code.
   * Press `Ctrl + Shift + P` and run **`Dev Containers: Reopen in Container`**.

3. **Verify the environment:**
   ```bash
   node -v
   pnpm -v
   ```

## Included Services

All services share the `${APP_NAME}-network` Docker network. From your Node.js app inside the container, connect using the **Internal Host** and internal container ports.

| Service | Image | Internal Host | Local Port (`.env`) | Default Access / Credentials |
| :--- | :--- | :--- | :--- | :--- |
| **App (Node 26)** | `devcontainers/typescript-node:26` | `app` | `3000` | `http://localhost:3000` |
| **SQL Server 2025** | `mssql/server:2025-latest` | `mssql` | `1433` | User: `sa` / Pass: `D3faultP@ssw0rd` |
| **PostgreSQL 18** | `postgres:18.4-alpine` | `postgres` | `5432` | DB: `defaultdb` / User: `postgres` / Pass: `D3faultP@ssw0rd` |
| **Redis 8** | `redis:8.8.0-alpine` | `redis` | `6379` | No password by default |
| **RabbitMQ 4** | `rabbitmq:4.3.2-management-alpine` | `rabbitmq` | `5672` / `15672` | UI: `http://localhost:15672` (`guest` / `guest`) |
| **Adminer** | `adminer:5.4.2` | `adminer` | `8080` | UI: `http://localhost:8080` |
| **pgAdmin 4** | `dpage/pgadmin4:9.16` | `pgadmin` | `5050` | UI: `http://localhost:5050` (`pgadmin@example.com` / `D3faultP@ssw0rd`) |
| **Redis Insight** | `redis/redisinsight:3.6` | `redis-insight` | `5540` | UI: `http://localhost:5540` |

> **Persistence:** Database data, message broker state, and the pnpm store (`/home/node/.local/share/pnpm/store`) are persisted in named Docker volumes.

## Production Build

The `Dockerfile` defaults to the `final` stage using `node:26-slim` running as the non-root `node` user on port `3000`:

```bash
docker build -t my-api:latest .
docker run -p 3000:3000 my-api:latest
```

## Optional: Terminal AI Agents (OAuth)

Since Node.js is already included in this DevContainer, you can install terminal-based AI agents directly inside the container:

```bash
npm install -g @google/gemini-cli
npm install -g @anthropic-ai/claude-code
npm install -g @openai/codex
npm install -g opencode-ai
```

To persist OAuth sessions and global rules across container rebuilds, add only the relevant folders to `.devcontainer/devcontainer.json`:

```json
"initializeCommand": "mkdir -p ${localEnv:HOME}/.gemini ${localEnv:HOME}/.claude ${localEnv:HOME}/.codex ${localEnv:HOME}/.config/opencode ${localEnv:HOME}/.local/share/opencode",
"mounts": [
  "source=${localEnv:HOME}/.gemini,target=/home/node/.gemini,type=bind,consistency=cached",
  "source=${localEnv:HOME}/.claude,target=/home/node/.claude,type=bind,consistency=cached",
  "source=${localEnv:HOME}/.codex,target=/home/node/.codex,type=bind,consistency=cached",
  "source=${localEnv:HOME}/.config/opencode,target=/home/node/.config/opencode,type=bind,consistency=cached",
  "source=${localEnv:HOME}/.local/share/opencode,target=/home/node/.local/share/opencode,type=bind,consistency=cached"
]
```
